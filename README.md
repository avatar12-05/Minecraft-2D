# Minecraft-2D
This JavaFX project is based on the 3D sandbox video game Minecraft but instead 2D. The player will be able to place and break blocks using left and right-click while moving with the controls WASD + jump. There is currently no intention of adding health or hunger bars but it may be added later. The game will be similar to creative mode with the ability to place or remove any block residing in the inventory without having to collect the items first.
